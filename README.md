# TiN 蝕刻文獻探索工具

這個工具是從大學專題延伸出來的研究整理原型。

最初是想協助整理 TiN 蝕刻條件。開始查資料後，我發現 Cl₂、Ar、N₂、壓力、功率、蝕刻時間、側壁角度等資訊散在不同文獻裡，每次比較都要重新翻資料，所以才把常用的條件整理成同一個介面。

目前的功能包含：

- 文獻條件整理與比對
- 鄰近條件插值
- TiN 蝕刻速率、側壁角度、選擇比估算
- 簡化側壁截面圖
- 條件提醒
- LOOCV 模型自我檢查

## 我在這個專案裡主要做的事情

我不是把這個專案定位成純程式作品。程式碼大多是在生成式 AI 協助下完成，我主要負責：

- 定義想解決的研究問題
- 規劃功能和操作流程
- 整理文獻資料欄位
- 決定輸入與輸出要怎麼呈現
- 反覆測試不同條件
- 檢查結果是否和文獻或製程概念互相矛盾
- 在資料不足或結果不穩定的地方加上限制說明

## 目前限制

不同文獻使用的機台、樣品和製程條件並不完全一致，側壁角度的實測資料也還很少，所以這個工具目前主要拿來整理文獻、看趨勢和找下一步值得驗證的方向，不適合直接拿結果決定實際製程 recipe。

## 執行方式

```bash
streamlit run app.py
```
